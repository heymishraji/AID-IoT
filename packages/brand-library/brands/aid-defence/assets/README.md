# AID Defence · assets

What goes here: logo masters and variants, imagery, icons, and the tactical symbol set for Lighthouse.
- `logo/`: master SVGs (`full`, `mark`, `mono`, `reversed`) plus `LOGO.md` (clear space, minimum size, misuse).
  Empty: no AID Defence mark exists yet.
- `symbology/`: symbol SVGs once the standard (MIL-STD-2525 / APP-6 / customer-specific) is confirmed.
  Colours come from the protected `symbology.*` tokens, never from the SVG files.
- `imagery/generated/`: AI imagery with a sidecar `<name>.md` (prompt, tool, date). Never real kit or sites.
