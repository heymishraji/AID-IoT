# AID IoT · templates

Empty by design: no visual direction exists yet. One folder per collateral type, each with a master file, a
`recipe.md` (content fields → layout) and approved `golden/` examples. Templates use semantic tokens only;
`npm run check` fails on any hard-coded colour.

Planned (priority order): `datasheet/`, `deck/` (Google Slides master), `social/` (formats.json + SVG),
`email-signature/`, `roll-up/`, then `brochure/`, `banner/`, `web/` page patterns.
