# AID IoT · assets

What goes here: logo masters and variants, imagery, icons and any brand-specific font files.
- `logo/`: master SVGs (`full`, `mark`, `mono`, `reversed`) plus a `LOGO.md` with clear space, minimum size and misuse.
  Current contents are the existing mark, kept as a **placeholder** until the logo route is decided
  (copied from the AID workspace repo's `assets/brand/`).
- `imagery/reference/`, `imagery/generated/`: every generated image ships with a sidecar `<name>.md` holding the
  prompt, tool and date.
- No colour values in file names or docs here; colours live in `../tokens/`.
