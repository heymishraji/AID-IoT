# AID Defence · templates

Empty by design: no visual direction exists yet. One folder per type, each with a master file, a `recipe.md`
(content fields → layout) and approved `golden/` examples. Templates use semantic and protected tokens only;
`npm run check` fails on any hard-coded colour.

Planned: `datasheet/` (cleared-for-release variant), `deck/` (briefing deck, Google Slides master),
`one-pager/` (problem → approach → private conversation), `classified-document/` (header/footer banners from
`classification.*`), `lighthouse-ui/` (night + compact console patterns), `email-signature/`.
