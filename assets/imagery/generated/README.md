# Generated imagery

AI-generated mood images. Every image has a sidecar `<name>.md` with the prompt, tool, model, date and review,
so it can be regenerated or refined in ChatGPT or Figma. Stored as JPEG (quality 82) to keep the repo light.
Stances come from `docs/brand/STRATEGY-CONTRAST.md`: AID IoT human and in context; AID Defence restrained,
placeless, people obscured, never weapons or real units.
